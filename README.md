# 📖 About The Project

**Smart College Complaint Management System (SCCMS)** is a web-based platform designed to digitize and simplify the complaint management process within educational institutions.

Traditional complaint systems often depend on:

```text
📝 Paper Forms
      ↓
📁 Manual Records
      ↓
👨‍💼 Manual Processing
      ↓
⏳ Delayed Response
      ↓
❓ No Proper Tracking
```

SCCMS transforms this process into a centralized digital workflow.

Students can submit complaints online, track their status and receive updates, while administrators can manage, categorize, prioritize and resolve complaints through a dedicated dashboard.

---

# 🚨 Problem Statement

College students encounter many issues related to:

```text
🏫 Infrastructure
🖥️ Computer Labs
📚 Academics
🧹 Cleanliness
💡 Electricity
🚰 Water & Facilities
📶 Internet
🚌 Transportation
🍽️ Canteen
🔒 Security
👨‍🏫 Faculty-related concerns
📋 Administrative issues
```

In a traditional system, students may not know:

* Where to submit a complaint
* Whether their complaint was received
* Who is handling it
* How long resolution will take
* Whether action has been taken
* What the final outcome is

This creates a lack of transparency and accountability.

---

# 💡 Our Solution

SCCMS provides a centralized platform where:

```text
                 👨‍🎓 STUDENT
                     │
                     ▼
              📝 SUBMIT COMPLAINT
                     │
                     ▼
              🔎 TRACK COMPLAINT
                     │
                     ▼
              👨‍💼 ADMIN REVIEW
                     │
          ┌──────────┼──────────┐
          ▼          ▼          ▼
       PENDING    IN PROGRESS  REJECTED
          │          │
          └─────┬────┘
                ▼
            ✅ RESOLVED
                │
                ▼
             👨‍🎓 STUDENT
```

The system creates a transparent connection between **students and administration**.


# 🚀 Installation

## 1️⃣ Clone The Repository

```bash
git clone https://github.com/YOUR-USERNAME/SCCMS.git
```

---

## 2️⃣ Enter The Project Directory

```bash
cd SCCMS
```

---

## 3️⃣ Install A Local PHP Environment

You can use a local PHP development environment such as:

```text
XAMPP
WAMP
Laragon
```

---

## 4️⃣ Place The Project

For XAMPP, place the project inside:

```text
xampp/
└── htdocs/
    └── SCCMS/
```

---

## 5️⃣ Start The Server

Open XAMPP and start:

```text
Apache  🟢
MySQL   🟢
```

---

## 6️⃣ Create The Database

Open your SQL database management interface and create a database, for example:

```text
sccms
```

Then import:

```text
database/sccms.sql
```

---

## 7️⃣ Configure Database Connection

Update the database configuration according to your local environment.

Example:

```php
<?php

$host = "localhost";
$username = "root";
$password = "";
$database = "sccms";

$conn = new mysqli(
    $host,
    $username,
    $password,
    $database
);

if ($conn->connect_error) {
    die("Database connection failed");
}
?>
```

---

## 8️⃣ Open The Application

Open the project through your local PHP server.

Example:

```text
http://localhost/SCCMS/
```
